# AI Automation Workflows

A collection of AI-powered automation projects built with **n8n**, integrating AI models, APIs, databases, and external services to solve practical problems.

This repository documents my hands-on learning in workflow automation, AI agents, retrieval-augmented generation (RAG), and system integration. Each project includes relevant workflow exports, documentation, and screenshots where available.

## Projects

### 1. Florence — Multimodal AI Gym Assistant

**Status:** Learning and development project

Florence is a Telegram-based AI gym assistant developed with n8n. It explores multimodal interaction and document-based retrieval using a RAG pipeline.

**Key concepts and technologies:**
- n8n workflow automation
- AI agent integration
- Retrieval-Augmented Generation (RAG)
- Supabase and vector embeddings
- Google Drive document ingestion
- Telegram text, voice, and image interactions
- Workflow debugging and data mapping

**Project resources:**
- [Florence project folder](./florence-multimodal-gym-assistant/)
- [Project README](./florence-multimodal-gym-assistant/README.md)

The project is intended for learning and experimentation. Workflow exports and integrations may require configuration and validation before they can be run in another environment.
